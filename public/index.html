TMDB API Key Required

To enable live discovery lists for Popular, Trending, Currently Airing, and Upcoming TV shows, configure a server-side TMDB API key:

  1. Sign up for a free developer account at themoviedb.org and obtain your API Read Access Token or API Key (v3).
  2. Add TMDB_API_KEY=your_key_here to your local .env file (or set the environment variable).
  3. Restart the MediaVault server. Credentials remain securely on the server and are never committed or exposed to the client.
